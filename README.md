Repositório dedicado à atividade prática "O Desafio da Baseline".

* **Instituição:** Universidade Federal de Goiás (UFG) - Instituto de Informática (INF)
* **Curso:** Engenharia de Software
* **Disciplina:** Gerência de Configuração de Software - 2026/1 
* **Professora:** Sofia Costa Paiva 

## Descrição
Este projeto atende aos requisitos da atividade prática, contendo:
* Uma estrutura de diretórios padronizada.
* Um código simples.
* Um arquivo de configuração padronizado (`config.env`).
* Um arquivo `CONFIG_MAP.md` listando todos os Itens de Configuração (ICs) e definindo a política de nomenclatura de versões com versionamento semântico.
* Uma baseline fechada usando uma Tag (`v1.0.0`) no Git.

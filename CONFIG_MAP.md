# Mapa de Itens de Configuração (ICs)

## 1. Itens de Configuração (ICs)
Abaixo estão listados os ICs controlados neste projeto:
* **Código Fonte:** `src/main.py`
* **Documentação:** `README.md` e `CONFIG_MAP.md`
* **Arquivos de Configuração:** `config/config.env`
* **Dependências:** Python 3 e o Git.

## 2. Política de Nomenclatura de Versões
Este projeto utiliza o **Versionamento Semântico (SemVer)** no formato `MAJOR.MINOR.PATCH`:
* **MAJOR (Maior):** Versão com mudanças incompatíveis na API ou grandes refatorações estruturais.
* **MINOR (Menor):** Adição de novas funcionalidades mantendo compatibilidade com a versão anterior.
* **PATCH (Correção):** Correções de bugs e pequenos ajustes que não afetam a estrutura principal.
